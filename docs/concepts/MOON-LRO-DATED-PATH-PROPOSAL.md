# Mother Earth · Dated LRO path on the Moon globe

**Rev 2 · 14 November 2026 · proposal for review**

Extend the Moon globe with the Lunar Reconnaissance Orbiter’s archived path for 10 June 2026 00:00 through 11 June 00:00 UTC. This is a docs-only addendum to `MOON-SUN-GLOBES-PROPOSAL.md` §3.1. The build would begin on a branch after Chad’s go. Live LRO positions, lunar lighting and Parker’s wider orbit each need a separate decision.

## What a visitor sees

- The Moon globe opens on the evenly lit near side. An off-by-default **Show LRO’s dated path** control sits with the globe controls. When on, the globe shows a three-dimensional flight path above the lunar sphere and a marker at the selected archived sample. The line joins sampled positions. Readout copy: **Dated LRO example · 10–11 June 2026 UTC** and **Calculated from NASA/GSFC’s definitive trajectory · [selected time UTC]**. Add **[altitude in km] above the reference sphere** for the selected minute. Explain that the line shows the spacecraft’s flight path above a spherical Moon and the marker is enlarged for visibility. Draw one flight path and one marker.
- Keep the existing spacecraft diagram and use its selected minute and previous/next controls as the single time selection. Give the globe overlay a direct link to those controls and echo the selected UTC minute beside the globe. Preserve `?t=` behavior: no parameter opens the example at 10 June 12:00 UTC, exact covered minutes use their archived sample, and an invalid, off-grid or out-of-range time shows the existing unavailable state and dated-example action. An unsupported time clears the overlay immediately. Selecting the dated example restores eligibility without changing the requested time silently.
- Match the existing diagram’s path window of 120 one-minute samples either side of the selected minute, clipped to the catalogue ends. Show the actual UTC bounds. The Moon hides geometry behind its sphere, including the marker and any label when occluded. The marker centre and path sit at the calculated altitude relative to the 1,737.4 km reference sphere. Preserve view direction as the time changes. Test the result at the limb, on the far side and across the texture seam.
- Keep textual UTC, source and nominal-altitude information available when the marker is behind the Moon. If the overlay cannot load or validate, say **Dated path unavailable on the globe** and keep the globe and independent diagram usable when their own inputs are available. If WebGL is unavailable, the diagram remains the fallback.

## Catalogue and transform

1. Use `lrorg_2026074_2026166_v01.bsp`, the definitive NASA/GSFC Flight Dynamics Facility trajectory in NASA PDS. Reuse the pinned segment in `phase1/skycraft/BUILD.json` and the existing decoder. The 1,441 native states are Moon-centred J2000, geometric, one minute apart including both endpoints. Transform the unrounded position at its native SPK epoch in TDB seconds past J2000. Retain the existing UTC keys for display and lookup. The source positions remain native samples throughout.
2. Use NAIF SPICE `pxform` from `J2000` into the explicit `MOON_ME_DE440_ME421` frame, with NAIF `moon_de440_250416.tf` and `moon_pa_de440_200625.bpc`, using SpiceyPy `8.0.0` with `CSPICE_N0067`. NAIF lists the older `moon_de440_220930.tf` in its historical directory. Pin and verify the selected kernel hashes, frame and package version in `BUILD.json`, and record the linked toolkit version from `tkvrsn('TOOLKIT')`. Use NAIF `naif0012.tls` for the independent UTC-to-TDB epoch check, with its hash recorded. The production rotation takes TDB directly from the SPK segment. The ME frame supplies the lunar mean Earth and rotation-axis convention. Keep Moon centre, apply the rotation once and preserve radius. Compute planetocentric latitude with `atan2(z, hypot(x,y))` and east-positive longitude with `atan2(y,x)` wrapped to [−180°, 180°). Use the globe’s existing geographic conversion for position and `radius / 1737.4 − 1` for altitude in globe-radius units. Draw straight segments between native samples. A chord of about 100 km at a radius of 1,802 km has about 0.7 km sag, with the lowest sampled altitude about 64.9 km. The pinned inertial states give a minimum chord altitude of 64.18 km. Test the actual Moon-fixed chords in the candidate because each endpoint is rotated at its own epoch.
3. Publish a small, immutable, same-origin Moon-fixed catalogue alongside the page, with a distinct revision tied to `craft-moon-2026-06-R1`. Record both source and output hashes, frame, radius, units, grid and sample count. Validate the pinned bytes and metadata before drawing. A static catalogue fits this finite, already archived day and needs no collector or new Worker route. Keep the existing R1 diagram source and fetch path so the two views can fail independently. Include reproducible offline generation from pinned inputs and list the new catalogue and its provenance in Sources & Details. File the catalogue, NAIF kernels and DE440 coefficient sources in the register before page release.
