## 3. Hub 0.6.5 — `/catalogue/sky/<revision>` (T3 contract)
- Exact own-key pin lookup (`SKY_REVISIONS`, frozen); raw-path match `^/catalogue/sky/([^/]+)$`.
- Unknown or malformed id, bare `/catalogue/sky`, any loose separator or extra segment → **404 `unknown revision`, no R2 read, no-store**. No unversioned URL, nothing serves "current".
- Known revision: R2 `ref/sky/sky-2026-11-R1.json`; missing → 503 `missing`; R2/read error → 503 `unreadable`; whole-file sha256 ≠ pin → 503 `integrity`; not JSON / wrong revision / a body without rows → 503 `invalid`; else the bytes, `ETag` = file hash, CORS `*`, max-age 60.
- Outside LAYERS, cron, D1, health and history. Index lists the route and `catalogues.sky`. Arts and Timeline routes untouched.

## 4. The card (`sky.js` + markup)
- Off on load; the switch "Show the two clocks" fetches `/catalogue/sky/sky-2026-11-R1` once (10 s timeout, no-store), checks the **sha256 in the page** and the shape (every row `[date, number > 0, number|null, UTC|UT~]`). Any failure → "Distances unavailable — the calculated data could not be loaded (reason)"; rows not drawn. The page never calls Horizons.
- Tabs Now / Deep Time (`tablist`/`tab`/`tabpanel`, roving tabindex, ←/→/Home/End, Enter/Space, click). Deep Time is static text in the page and never waits for the file.
- Now: Moon (±17 d) and Sun (±182 d) rows: distance (Moon to 1 km, Sun to 0.1 million km), "at 00:00 UTC, <date>", `UT~` days flagged next to the timestamp, direction from range rate (RR < 0 closer, > 0 farther, = 0 neither, missing → none, **no fallback**), chart (SVG, own scale with units, today marker, "calculated ahead" region, outside-range shading, gaps never joined, Sun sampled extrema marked) and a visible text equivalent.
- Dates: today = UTC date of the device clock, **exact match only**; outside coverage and missing-inside have different wording; last available shown separately. Recomputed on switch-on, on the page's 5-min tick, and on `visibilitychange`.
- Details: method, date rule, direction rule and the time-scale note generated from the catalogue: "From 4 Feb 2027, Horizons marks the times as estimates … samples from 1 Jul 2027 would be off by one second until the next refresh."
- Deep Time wording as proposal rev 3 §1.2 (L1 mechanism; "hundreds of millions of years" on the card, ~650 Myr in Sources; widening "estimated from changes in Mercury's orbit consistent with solar mass loss").
